# DataViz-PRA2

# Contingut del repositori
- *data_processing.ipynb*: jupyter notebook amb el codi del projecte
- *requirements.txt*: dependències de python a instal·lar per executar el codi
- *links.txt*: enllaços a kaggle i la presentació de Flourish
- *plot_colors.txt*: colors emprats a Flourish per cada gènere musical
- *spotify_songs.csv*: dades de Spotify en format csv
- *plot_data*: directori on es guarden les dades processades per crear visualitzacions
